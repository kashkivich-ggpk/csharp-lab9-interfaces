## Сборка и запуск

```
dotnet build
dotnet run
```

## Что демонстрирует программа

Класс `TestClass` реализует три интерфейса с одноимёнными методами. Явная реализация позволяет вызывать нужную версию метода через приведение объекта к конкретному интерфейсу.
